# Журнал решений

## D1. whisper.cpp CLI (сабпроцесс) вместо WhisperKit / MLX
**Решение:** гоняем системный `whisper-cli` (Homebrew), путь и модель настраиваются.
**Почему:** уже установлен у целевого пользователя; ноль зависимостей в SwiftPM; модели уже лежат в `~/.cache/whisper`; WhisperKit — кандидат на M2+ если понадобится word-level тайминг из коробки.
**Следствия:** нужен установленый whisper-cpp (`brew install whisper-cpp`) — фиксируем в README; модель пользователь выбирает сам (по умолчанию medium-q5_0 как баланс качество/скорость для русского).

## D2. Ноль внешних Swift-пакетов
**Решение:** только Foundation/AVFoundation/SwiftUI, парсинг аргументов руками.
**Почему:** офлайн-сборка, вечная воспроизводимость, минимум поверхности атак. CLI простой, argument-parser не оправдан.

## D3. Три «мозга» в M0, подписочные OAuth — в M2
**Решение:** v0.1 — universal-коннекторы: OpenAI-совместимый (`/chat/completions`), Anthropic-совместимый (`/v1/messages`), Ollama (`/api/chat`). Подписочный логин Codex/Claude — отдельная веха: там OAuth-флоу и переиспользование CLI-токенов (паттерн OpenClaw, см. docs.openclaw.ai/concepts/oauth).
**Почему:** universal-эндпоинты покрывают GLM Coding Plan уже сегодня (Anthropic-совместимый эндпоинт Coding Plan — см. zcode.z.ai), а OAuth-флоу — отдельный пласт риска и тестирования.
**Правило:** base URL и ключ всегда вводит пользователь; приложение не хардкодит ничьи эндпоинты и не перепродаёт доступ.

## D4. Хранилище — файлы JSON + аудио, без БД в v0.1
**Решение:** `~/Library/Application Support/Stenograf/meetings/<uuid>/{meta.json, audio.wav, transcript.md, transcript.json, summaries/*.md}`.
**Почему:** прозрачность (юзер видит свои данные), бэкапится копированием. SQLite FTS — в M3 вместе с поиском по встречам.

## D5. Конфиг — `~/.stenograf/config.json` (JSON, Codable)
**Решение:** без TOML/YAML-зависимостей, обычный JSON с примером в репозитории.
**Почему:** Codable из коробки, юзер правит блокнотом.

## D6. Запись — AVAudioRecorder, 16 кГц моно 16-bit WAV
**Почему:** это нативный входной формат whisper.cpp, без перекодирования. Системный звук (ScreenCaptureKit) — M2, сценарий M0 — живые встречи с микрофоном.

## D7. Язык интерфейса и промптов — русский, транскрипция — авто/ru
**Почему:** ниша «Granola для русскоязычных» пуста (см. исследование: Apple-транскрибация русский не поддерживает, Granola платная с зарубежной картой, MacWhisper €64).

## D8. Меню-бар приложение через SwiftPM executable + скрипт-обёртку .app
**Решение:** без .xcodeproj в репо; `scripts/make-app.sh` собирает минимальный .app-бандл (Info.plist: LSUIElement, NSMicrophoneUsageDescription).
**Почему:** репо собирается `swift build` у кого угодно; Xcode-проект и нотаризация — когда пойдём в продажу (Apple Developer $99/год).

## D10. Иконка приложения — вариант B «Микрофон»
**Решение (2026-10-08):** выбрано пользователем из трёх вариантов (A монограмма / B микрофон / C лист протокола); первый авторский вариант (волна→строки) забракован как «непонятный».
**Урок:** абстрактные метафоры не проходят — символ должен читаться за полсекунды (микрофон = диктофон). Генератор: `scripts/make-icon-variants.swift`, сборка .icns — в `scripts/make-app.sh`.

## D9. ChatGPT-подписка — через официальный codex exec, а не напрямую в приватный API
**Решение (2026-10-08, по требованию пользователя «логинюсь своим ChatGPT, без ключей»):** главный мозг `chatgpt` (kind: codex) вызывает системный Codex CLI: `codex exec --skip-git-repo-check -s read-only -o <файл> "<промпт>"`. Токен подписки берётся CLI-ем из `~/.codex/auth.json` (режим auth_mode=chatgpt), обновляется им же.
**Почему:** (а) это официальный инструмент OpenAI — «Sign in with ChatGPT» задуман как OAuth для приложений; (б) лимиты/refresh/ретраи подписки обрабатывает OpenAI, а не мы; (в) прямой HTTP в `chatgpt.com/backend-api/codex/responses` (реверс-инжиниринг по Simon Willison) — хрупко и требует самому крутить refresh-токены.
**Установка CLI:** npm в пользовательский префикс `~/.stenograf/cli` (`@openai/codex` + платформенный алиас `@openai/codex@latest-darwin-arm64`), резолвер путей проверяет `~/.stenograf/cli/bin`, `/opt/homebrew/bin`, `/usr/local/bin`.
**Правило D3 остаётся:** никогда не перепродаём доступ; вход всегда личный, бесплатный, open-source.
