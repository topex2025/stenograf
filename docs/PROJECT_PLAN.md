# Stenograf — план проекта

Позиционирование: **открытая память переговоров для Mac** — записывает встречу, транскрибирует локально (Whisper), резюмирует через ИИ-подписку, которая уже оплачена пользователем (ChatGPT/Codex, GLM Coding Plan, Claude, Ollama). Никаких собственных подписок и облаков. Русский — из коробки.

## Принципы

1. Бесплатное open-source ядро (MIT), навсегда без подписки.
2. Аудио и транскрипты не покидают Mac, кроме явной отправки текста в выбранный «мозг».
3. Продавать можно только фичи (трекер обещаний, CRM-коннектор), никогда — доступ к моделям.
4. Ноль внешних зависимостей в сборке (SwiftPM без third-party пакетов).
