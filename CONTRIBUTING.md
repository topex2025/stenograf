# Как участвовать в разработке Стенографа

Спасибо, что хотите помочь! Проект маленький и дружелюбный — барьер входа минимальный.

## Быстрый старт для контрибьютора

```bash
git clone https://github.com/topex2025/stenograf.git
cd stenograf
scripts/setup.sh        # whisper.cpp + модель + codex CLI + нейроголос (одной командой)
scripts/verify.sh       # сборка + все тесты + CLI-смоук — должно быть зелёным
```

Требования: macOS 13+, Xcode Command Line Tools (Swift 6), Homebrew.

## Правила проекта (коротко)

1. **Ноль внешних зависимостей** в SwiftPM — только системные фреймворки (SwiftUI, AVFoundation). Новая библиотека = сначала issue с обоснованием.
2. **Приватность прежде фич**: аудио и транскрипты не покидают Mac; наружу уходит только текст транскрипта в выбранный пользователем «мозг». Никакой телеметрии — никогда.
3. **Никогда не перепродаём доступ к моделям**: приложение бесплатное, вход всегда личный (подписка/ключ пользователя). Платными могут быть только фичи.
4. **Строки интерфейса — через `L10n`** (Sources/StenografCore/L10n.swift), на всех трёх языках: ru / en / es. Тест `L10nTests` упадёт, если забыли перевод.
5. **Тесты обязательны** для новой логики в Core (у нас 30+ юнит-тестов; E2E-тест транскрипции пропускается сам, если нет whisper-cli).
6. Комментарии и коммит-сообщения — по-русски или по-английски, как удобнее.

## Структура — куда смотреть

| Что | Где |
|---|---|
| Модель данных, конфиг | `Sources/StenografCore/Models.swift` |
| «Мозги» (ChatGPT-подписка через codex exec, OpenAI/Anthropic-compat, Ollama) | `Sources/StenografCore/Brains/` |
| Транскрипция (whisper.cpp) | `Sources/StenografCore/Transcribe/WhisperCLI.swift` |
| Автопротокол после записи | `Sources/StenografCore/Pipeline.swift` |
| Поиск по встречам (русская морфология) | `Sources/StenografCore/Search/MeetingSearch.swift` |
| Ответы на вопросы по встречам | `Sources/StenografCore/AnswerEngine.swift` |
| Интерфейс (окно, вопрос, плеер, озвучка Piper) | `Sources/StenografApp/StenografApp.swift` |
| CLI | `Sources/stenograf/main.swift` |
| Решения и почему так | `docs/DECISIONS.md` |

## Пул-реквесты

1. Форк → ветка `feature/что-делаете` (или `fix/...`).
2. `scripts/verify.sh` зелёный локально.
3. PR в `main`: что изменили, зачем, как проверили. CI на GitHub Actions прогонит сборку и тесты на macOS-раннере.
4. Идеи посложнее — сначала issue, обсудим.

## Известные направления (ждём помощи)

- Разметка «кто говорит» (диаризация) — главная желанная фича.
- Системный звук Zoom/Google Meet (ScreenCaptureKit).
- Локализация на другие языки (структура `L10n` готова).
- Улучшения нейроголоса (больше моделей Piper, автозагрузка голоса под язык ответа).
- Windows/Linux — ядро Core переносимо, нужен UI-слой.
